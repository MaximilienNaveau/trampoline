# Textures

`box_lid.jpg` — the start screen's closed box lid (see box_lid.gd); its
plain painted middle also paints the board's frame (see board_view.tscn).
Generated from scratch with ImageMagick (noise smeared into brush strokes,
mint-green colour ramp, brown dry-brush streaks for the wood showing
through, mitred bevel frame), matching the real lid's paint in
`doc/real-game/`. Original work, no third-party source.

`ribbon_bow.svg` — the orange bow on the lid. Hand-written SVG, original
work.

`lid_underside.jpg` — the back of the start screen's box lid, seen while
it turns over (see box_lid.gd). Generated from scratch with ImageMagick:
the painted middle of `box_lid.jpg` (so it's the exact same green as the
lid's top) with a wood grain soft-light-blended into it (wavy grain lines
from a noise-perturbed sawtooth, plus motion-blurred fibres). Original
work, no third-party source.
